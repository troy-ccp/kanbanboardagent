**Created:**
- `kanban-board.html` - Simplified, local file-based kanban board with web viewer
  - Clean UI with 4 columns: Backlog, In Progress, Review, Done
  - Auto-refreshes every 10 seconds
  - Reads from `data/tasks.json`
  - Priority badges (Low, Medium, High, Urgent)
  - Subtask progress tracking
  - No external dependencies - works entirely locally
  - Windows-friendly

**To use:**
1. Open `C:\Users\coach\.openclaw\workspace\kanban-board.html` in a browser
2. Manage tasks via CLI: `node scripts/kanban-cli.js`
3. Board auto-refreshes to show changes

**CLI Commands:**
- `node scripts/kanban-cli.js add "Task title" high` - Add new task
- `node scripts/kanban-cli.js list` - List all tasks
- `node scripts/kanban-cli.js status <task_id> in_progress` - Change status
- `node scripts/kanban-cli.js complete <task_id>` - Mark as done
- `node scripts/kanban-cli.js delete <task_id>` - Delete task
