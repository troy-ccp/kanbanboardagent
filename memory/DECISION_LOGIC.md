# Decision Logic

## Before Starting Work, Ask:
1. **Strategic or tactical?** → Strategic first
2. **Dependencies?** → Dependent tasks after prerequisites
3. **Will this become obsolete?** → Decide direction first
4. **Blocking other work?** → Clear debt before new work

## Priority Order:
1. Strategic decisions
2. Technical debt
3. Enhancements
4. Business work
5. Personal/family
